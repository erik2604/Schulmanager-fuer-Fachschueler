# Schulmanager-fuer-Fachschueler

Creator:
Erik Schiefele / Nils Bräunlein

Der Schulmanager für Fachschüler ist eine webbasierte Anwendung zur strukturierten Verwaltung von Noten und Schulterminen. Ziel ist es, Fachschülern einen besseren Überblick über ihren aktuellen Leistungsstand sowie anstehende Prüfungen und Aufgaben zu ermöglichen.

Die Anwendung erlaubt es, Noten nach Fächern und Leistungsarten zu erfassen, automatisch gewichtete Durchschnittsnoten zu berechnen und Termine übersichtlich darzustellen.

Funktionen
- Benutzerregistrierung und Login
- Notenverwaltung pro Fach
- Automatische Berechnung von gewichteten Notendurchschnitten
- Terminverwaltung (inkl. Anzeige der nächsten 14 Tage)
- Übersichtliche Darstellung aller Noten
- Benutzerbezogene Daten

Verwendete Technologien
- Backend: Python (Flask)
- Frontend: HTML
- Datenbank: SQLite
- Versionsverwaltung: GitHub


Hinweis:
Dieses Projekt wurde im Rahmen eines Schulprojekts entwickelt und ist nicht für den produktiven Einsatz optimiert!
